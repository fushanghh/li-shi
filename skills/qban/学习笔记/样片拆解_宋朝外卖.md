# 样片拆解：宋朝外卖（抖音，68.8秒，1280×720，30fps）
镜头切点约：9.0 / 17.5 / 24.0(红圈圈入) / 28.5 / 37.0 / 43.0 / 47.5 / 56.0 / 65.5 → 10个镜头，每镜5–9秒，一镜一句话。
24–28s、44–47s 持续平移（街景横摇/夜市横移）；其余镜头基本静止机位，靠人物和贴纸动。转场以硬切+短暗场为主，重点处用红圈圈出。
音轨全程不间断（无0.5秒以上静音），可能有口播/配乐——我听不到，未判断。

## 画风
- 扁平矢量，不描粗黑边，靠色块+暗一档的同色描边；细节少而干净。
- 每镜一个主色调：宫内暗红、街市旧纸米黄（清明上河图感）、夜市深蓝+橙灯笼光晕、信息图近黑、结尾深棕。
- 背景人物降级为无五官的圆头+梯形“路人剪影”，主角才有五官（主次分明）。

## 人物与表情
- 头≈身，白圆脸、两团粉椭圆腮红；手是身前两颗白圆球；袍子梯形+V领+袖子暗一档。
- 表情库：平静=小黑点眼+短嘴；开心=^^弧线眼+弯嘴；大笑=弧线眼+张大红嘴；震惊=两个白圈大眼(黑瞳)+O形嘴；紧张=蓝色汗滴；配合动作（捧盒、端碗、抬手）。
- 头顶名牌：深色小框+金边，灰色小字前缀+白色大字（“宫外 外卖小哥”“宋朝叫 闲汉”）。
- 宋皇帝：直脚幞头长翅，黄袍。

## 文字
- 两层字幕：上行小号白字铺垫（“南宋元宵夜，皇帝嘴馋了，”），下行超大号金色或红色重点句（“点了份外卖。”），下方一条由左向右渐隐的细金/红线。重点出现时带一点模糊→清晰的显影。
- 贴纸气泡字：倾斜手写粗体、白/黄字深色描边，贴在人物旁（“双倍！”“赏！”“老板！来一份！”“数不过来！”）。
- 数据：超大金色数字“72”+小字单位，下面一个出处小框“《东京梦华录》在京正店七十二户”。

## 道具与信息图
- 食盒拆解图：三层红色食盒竖向拆开，每层配碗+热气，右侧标签框“上层 鱼羹/中层 圆子/夹层 热水·保温”，背后一个暗色圆形聚光。
- 城市点阵图：深色网格汴京，中间“皇城”框，房子图标+金点逐个弹出，蓝色河道。
- 结尾菜单：横杆挂一排竖向木水牌，小字店名+大红竖排菜名（李婆婆鱼羹、南瓦张家圆子……）。
- 店招：竖条白底红字（包子、茶坊、羹店、酒），红灯笼带光晕。
