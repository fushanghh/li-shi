# 历史/科普视频制作规则（2026-10-21 起新画风，冲突处以新画风为准）

## 新画风（学自“宋朝外卖”抖音样片，拆解笔记见 学习笔记/样片拆解_宋朝外卖.md）
1. 节奏：一镜一句话，每镜约 4–6 秒；全片 1.5–2.5 分钟为宜。机位多数静止，靠表情/贴纸/道具动；只在表现“多”时横移。转场硬切或极短暗场，证据处用红圈圈出。
2. 文案：先写成一条清楚的知识链（钩子问题→答案先给→2–4 个知识点各配一个证据→一个案例→一句总结/互动提问），每句口语、短、有信息量；不堆细节，不拐弯。
3. 色调：每章一个主色调（宫内暗红、街市旧纸米黄、夜景深蓝+橙灯笼、数据近黑、结尾深棕），更亮更暖，主体清楚。
4. 人物：扁平无粗黑边（用同色暗一档勾形），头≈身，白圆脸+粉椭圆腮红，手为身前两颗白圆球，梯形袍+V领、袖子暗一档。主角有五官，路人为无五官圆头梯形剪影。头顶名牌：深色小框金边，灰色小字前缀+白色大字。
5. 表情：平静点眼短嘴；开心^^弧眼；大笑弧眼张大红嘴；震惊白圈大眼黑瞳+O嘴；紧张蓝汗滴。表情与动作、贴纸字同时出。
6. 字幕两层：上行小号白字铺垫，下行超大重点句（金色；反差/惊人用红色），下面一条由左向右渐隐细线，模糊→清晰显影。人物旁加倾斜手写粗体贴纸吐槽字（白/黄字深描边）。数据用超大金色数字+小单位+出处小框。
7. 道具做成信息图：拆解爆炸图带标签框、点阵地图图标逐个弹出、竖条店招、横杆挂竖排水牌等。
8. 帽子两侧摆动：帽子两侧有伸出部分（乌纱帽帽翅、宋直脚幞头长脚、唐软脚幞头垂脚、清暖帽红缨/翎子等）都随呼吸/走路/说话上下轻弹，左右略错相位，走路幅度加大，停下有余震回弹。
9. 无口播只音效、古文必接白话、史实核实标出处、交付前逐场景抽帧检查。

## 环境准备
`pip install cairocffi pyshp scipy numpy pillow`；`mkdir -p ~/.fonts && cp 字体/*.otf 字体/*.ttf ~/.fonts/ && fc-cache -f`。有方块乱码就补装 Noto CJK。需要 ffmpeg。

## 制作方式
1. 纯代码生成（Python + cairo 逐帧 + ffmpeg），不用 AI 生图，无口播。
2. 1920x1080，16:9 铺满。
3. 只给文案时自己拆镜头、设计动画；图解优先于装饰；每期重新设计视觉隐喻。
4. 不插纯色字卡：年份、原文、重点句直接叠在正在演的场景上。

## 声音
只要音效（字幕出现、盖印、数字弹出、转场），不要背景音乐。

## 画面
1. 第 0 帧必须有主体和标题，不能黑屏。
2. 线条干净，不要整层模糊光晕。
3. 字幕粗衬线体 60–88px，白字深描边；重点金色，危险红色。
4. 底部灰色小字标出处，示意图加“画面为示意”。

## 历史类专用
1. 服饰建筑跟朝代：唐软脚幞头圆领袍；宋直脚幞头；明乌纱帽补服；清暖帽辫子；秦汉冠深衣高台。
2. 引古文：“原文：”后必须紧跟“白话：”，每一句都算。
3. 钩子：第 0 帧出悬念大字，配 4–5 秒动画演绎，不能静态字卡，基于查实史料。
4. 结构：钩子 → 答案 → 证据 → 案例 → 总结/互动提问。
5. 案例故事须有资料可查，野史笔记标“据《××》记载”，不凭空编。
6. 用户标题只作参考，钩子按查实内容重新总结。

## 地图与地形
0. 地形不用金色/金黄配色。用灰褐/青灰山体+多向明暗晕渲，平原提亮，江河清楚的蓝，海岸细浅蓝线不发光；地名深底白字框，对比强。直接用 `最新代码/减灶骗人/terrain.py` 与 `dy.py` 的 maplabel()。
1. 真实高程（AWS Terrarium）+ Natural Earth 河流海岸；今河道标“示意”。
2. 路线白色发光虚线逐段画出；镜头慢推慢移；推近用更高精度高程。

## 交付前检查
渲染前出抽帧表，一次渲染到位；渲染后每场景抽一帧查：乱码、文字溢出、亮度、地图清楚、人物五官帽子是否被挡。

## 渲染流程
- 新一期：复制 `最新代码/减灶骗人/` 到新目录，把脚本里的 `/workspace/work/...` 改成新目录。

- 每期先写 research.md（原文+出处 URL，优先 ctext / 维基文库）。
