# 历史/科普视频制作规则（截至 2026-10-15）

用户给题目或文案、让做科普/历史视频时，一律按本规则执行。

## 资料位置（本资料包根目录）
- `制作规则.txt`：用户原版规则（本文件已整合并更新，以本文件为准）
- `参考样片/`：唐朝盐政（历史画风）、宋代军情（写实地形+字幕+结构）、历史人物道具样片
- `参考截图/`：写实地形.jpeg（地图标准）、IMG_8797/8798（字幕叠画面、粗描边大字）、Q版人物总表.png（人物标准）、暗色调标准.jpeg（色调标准）
- `代码/chibi.py`：大头Q版人物库，`chibi(c, x, yf, s, era, role, pose, face, expr, walk, prop, T, a, robe, p)`；era=qinhan/nanbei/tang/song/ming/qing，role=official/scholar/emperor/peasant/soldier/merchant/lady/kid/bandit，pose=stand/bow作揖/kneel/raise/hold/point/cheer/think，expr=calm/happy/shock/sad/angry/sleep，prop=scroll/cup/tablet笏板/hoe/spear/lantern/seal/coin/book/token/sickle。p=动作完成度0→1。直接运行会输出角色总表自检。
- `代码/最新一期_三餐/`：最新成片完整代码（hist.py 字幕与文字函数，px.py 建筑/公堂/道具，scenes.py 场景，含 quote() 古文+白话卷轴，sfx.py 音效，go2.sh / seg.sh 渲染+混音，research.md 资料出处示例）。新题目以它为模板改写。
- `代码/南京城墙示例/`：写实地形着色（shade.py）、底图（relief.py/mkchina.py）等。
- `代码/地图工具/terrain.py`：AWS Terrarium 高程瓦片 + Natural Earth 海岸/湖泊/河流。
- `字体/NotoSerifSC-Bold.otf`

## 环境准备（每次新沙箱先做）
`pip install cairocffi pyshp scipy numpy pillow`；`mkdir -p ~/.fonts && cp 字体/*.otf ~/.fonts/ && fc-cache -f`。出现方块乱码就补装 Noto CJK 全套字重。工作目录放 `/workspace/work/<题目>/`，复制模板代码改写，渲染脚本里的路径改成新目录。

## 制作方式
1. 纯代码生成动画（Python + cairo 逐帧 + ffmpeg），不用 AI 生图，没有口播。
2. 1920x1080，16:9 铺满。不限时长，讲明白为准。
3. 只给文案时自己拆镜头、设计动画；图解优先于装饰。
4. 不套固定模板：每期按内容重新设计视觉隐喻（别老用天平、水位、点阵）。
5. 不要单独的纯色背景字卡/原文卡插在中间：年份、人物、原文引文、重点句都直接叠在正在进行的动画场景上（原文以卷轴/书页/字幕浮在场景里，人物同时在演）。
6. 成片只在聊天里发。用户没说“传”就不上传网盘、不发邮件。

## 声音
只要音效（字幕出现、盖印、数字弹出、转场等），不要背景音乐。

## 画面与亮度
1. 背景以暗色为主：深夜蓝、深暖棕、暗红的背景压暗，用聚光/暖色光池把主体（人物、关键道具、图解、字幕）照亮，形成明暗反差。主体必须亮、清楚。标准样张：参考截图/暗色调标准.jpeg。要点：远景近黑暖棕（约 RGB 15,11,8），不用蓝色渐变天空、不用亮雪地；山影建筑是低饱和深棕剪影（约 40,31,22 → 82,56,33），细金线勾边；亮点是暖色灯笼光晕（约 185,92,58）和少数关键道具高光；人物主体米白/奶油色（约 201,181,144）；零星灰尘粒子；整体低饱和、高对比、像夜里点灯。
2. 第 0 帧就要有主体或标题，不能黑屏。
3. 线条干净，细线加粗，不要整层模糊光晕。
4. 字幕压在画面上（常在左上，但别固定一列把画面挤到一边），人物和图解做大。
5. 字幕：粗衬线体（Noto Serif CJK SC Bold），60–88px，白字深色描边。一句拆 2–3 行逐行出，前行保留，最多 3 行，旧的上滚；字逐个弹出。
6. 重点词金色+手绘下划线，危险/惩罚词红色；重点句单独放大居中。
7. 每个场景镜头推拉平移（放大约 1.3–1.8 倍对准主体），转场轮换缩放淡入、推入滑动、圈入等。
8. 底部灰色小字标出处，示意图加“画面为示意”。

## 节奏
要快。每屏停到刚好读完；场景约 7–10 秒；字幕出得快，行间少留空；一屏一件事。

## 历史类专用
1. 人物画风：大头Q版。头身比约 1:1.2（s=1 时全身约 300px，头直径约 136px），圆脸，点状眼睛+腮红+小嘴，有表情；短粗手臂、圆手、小脚；描边干净；黑色帽/发用暖灰亮边勾轮廓，防止在暗背景里消失。动作要演出台词（作揖、跪、举杯、指、捧卷轴），走路带弹跳，待机有呼吸和眨眼。人物通常放大到 s=1.4–2.0。
2. 场景和道具扁平矢量画风，扁平但细致；完整的年代建筑与环境，层叠剪影、粒子、暖色光池。Q版人物配建筑时可把建筑稍微缩小/圆润化。
3. 服饰和建筑跟朝代一致：唐软脚幞头圆领袍；宋直脚幞头加宋式殿宇；明乌纱帽、网巾/方巾、补服加明式建筑；清暖帽、辫子、补褂加清式建筑；秦汉冠和深衣加高台建筑。缺的身份/服饰就在 chibi.py 里补。
4. 配色：深暖棕、暗红、深蓝夜色；金色强调，红色警示。
5. 引古文：“原文：”金色引号句，紧跟“白话：”现代文。**每一句古文引文——字幕、台词、卷轴上的都算——后面都必须紧跟一句白话翻译讲明白意思，不能只放古文**（例：“饔飧而治”→白话：“一边自己做早晚两顿饭，一边治理国家”）。做法见 代码/最新一期_三餐/scenes.py 的 quote()。
6. 可用信息图：红色标签格、日历纸、红色虚线路线地图、扇形卡片、时间轴、时辰轮盘，以及Q版小人做反应（pose='think' 自带问号）。
7. 钩子标题开头：前几秒先放一句自己总结的悬念/反差大字，第 0 帧就出现，约 2–3 秒，关键词金/红色，配重音效；钩子必须配动画演绎（约 4–5 秒：Q版人物+场景把悬念演出来，第二行标题在冲突瞬间弹出），不能是静态字卡；标题放画面上部；必须基于查实史料。
8. 结构：钩子标题 → 具体开头物件 → 问题 → 贯穿全片的主视觉（地图/轮盘等，图标累积保留）→ 溯源 → 逐步拆解制度 → 案例故事 → 呼应开头 → 现代类比。
9. 用户自带资料照用：用户说是自己独家查到的资料，不核实、不否决、不改写，照原意做进片子；自己补充的内容须有可靠出处。
10. 每期都加案例故事增加观赏性：主动引用相关的历史事件、断案故事、笔记小说、民间传说等，用Q版人物把情节演出来。故事不必是严格信史，但必须有资料可查（正史、笔记、类书、古籍等），标出处；野史笔记类标“据《××》记载”。不要凭空编故事。
11. 用户写的标题只作参考，不原样放进片子（钩子标题按查实内容重新总结）；真实但戏剧化的标题不加“纠偏”段，直接做扎实科普。

## 地图与地形
1. 写实地形：真实高程（AWS Terrarium）做灰褐色多向光晕渲，保留山地纹理。海湖蓝色，岸线河流蓝白光，长江黄河加粗。用 Natural Earth 数据。
2. 路线白色发光虚线逐段画出；地名用上下两道金线夹住的大字标签；重点线金色发光。镜头慢推慢移。
3. 推近镜头用更高精度高程，别放大低精度。

## 交付前检查
渲染前先出抽帧表检查，一次渲染到位；渲染后每场景至少抽一帧查看：乱码、文字溢出、亮度、Q版人物是否清楚（帽子轮廓、五官没被道具挡住）。然后发成片。
