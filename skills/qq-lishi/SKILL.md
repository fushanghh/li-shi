# qq历史 画风与讲解法（学自“唐朝彩礼”抖音样片）

参考样片与截图：`/workspace/skills/qq历史/`（参考样片_唐朝彩礼.mp4，参考截图/）。只用来对照“方法”。

## 铁律
只学画风和动画讲解方法，不照抄样片的建筑造型、门楼、道具、人物造型、构图和台词。每期的建筑、道具、角色、视觉隐喻都自己重新设计。
总规则：所有元素都按本集文案画，每个镜头的背景、建筑、道具、动作都表现那句字幕的具体内容；不要每集背景和内容都一样，不需要省 token。
再要求：人物要丰富、会说话（张嘴+对话气泡）、会走路走位；背景不要一直一种；特效该加就加（火、烟、蒸汽、臭气/香气波纹、苍蝇、闪电、震屏、推镜等）；“你就是导演，不能每部戏都来一样的”。可复用 /workspace/work/shipin 的 fx.py（say/walkx/cam/shake/fire/stink/aroma 等）和 chibi2.py（talk 张嘴、flip、tint、apron、表情 sick/disgust/sniff/pain、姿势 belly/nose/carry/give/slam/sneak），但每期场景仍要新画。

## 技术底座
纯代码（Python + cairo 逐帧 + ffmpeg），1920×1080、30fps，无 AI 生图。复用 `qban` 的工程（/workspace/skills/qban/最新代码/、chibi2.py 人物库、渲染脚本），开工前先 load `qban` 看环境步骤。默认无口播，只配音效。

## 画风
1. 色调：整片统一暖棕/旧纸褐（#3a2a1f–#7a5a40）为底，大暗角 + 场景中央一团柔和顶光；夜晚深蓝灰配暖色灯、宫殿金黄、律法段米白墙面，始终低饱和、复古。空中少量缓慢飘浮的尘粒。
2. 舞台式横版：像侧面看戏台，一条水平地面线，人物站成一排；前景主体清楚，后景建筑/山影压暗一档、略虚，两三层纵深。镜头基本静止，只在“很多/排队/一路数过去”时横移。
3. 人物：Q版大白圆头、粉腮红、头≈身、小身体、无粗黑边；按身份换袍色，帽子按朝代且帽翅/软脚会弹动。主角有五官+夸张表情（^^ 笑、O 嘴、黑线、汗滴、头顶“？”“！”）；同一角色整片保持一致。
4. 道具即信息图：一个贯穿全片的符号道具（每期自己设计）；竖排卷轴写原文关键句，关键字标红；数很多时右上角“已数 N 个”大计数器；增长用红色上箭头；数量对比用堆叠实物当柱状图；关系用红线织网；重点物件背后放射光芒+地面红色椭圆圈；想象用椭圆气泡框。
5. 角落：卷轴下方灰色小字出处；右下角固定小字“人物和场面都是示意”。

## 字幕（核心）
1. 固定左上角，粗衬线白字，后面一团深色烟雾状暗影衬底，不用底框。
2. 一句话分短语逐行出现，同一段落内逐行累积（2–3 行），段落讲完整块清掉再开新段。
3. 显影动画：每个字从放大、模糊、半透明快速缩回落定（约 0.15–0.25 秒/字，逐字错开）。
4. 关键词换色+下划线：反差/禁止/负面用红色，人名、年号、专有名词用浅蓝。
5. 字幕说一句，画面同步演一个动作，字与动作同拍。

## 讲解法
1. 用一个具体的小东西或规矩当线索，从朝廷的问题讲到普通人身上。
2. 结构：反常钩子 → 朝廷为什么管 → 第一招怎么做 → 谁不买账 → 加码 → 精确数字落地（换算成普通人懂的单位）→ 结论（结尾不固定，按文案编，可联系现代生活给提醒）。
3. 一句一动作，但场景连续：同一舞台演完一整段，换段才换场景。
4. 古文只放在卷轴道具上做证据，字幕永远是大白话；每条史实查原文出处标在画面。
5. 节奏轻快幽默，靠表情和小动作抖包袱，信息密度高、数字具体。
6. 开头先概括全片讲什么、让人想看；一个核心观点贯穿；全白话。

## 交付前检查
先出抽帧表，渲后逐场景抽帧看字幕重叠、裁切、亮度、人物被挡；确认右下“示意”和出处小字在。
