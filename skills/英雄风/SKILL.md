# 英雄风（2026-10-31，学自用户给的戚继光抖音样片，首片《左宗棠·收复新疆》）

一句话：**战争风暗金地图 + 金线描英雄兵器对砍 + 戚继光样片的剪法**。用参考视频的 BGM 按拍排镜，地图战略推进和实景刀兵交锋交替，高潮密集切镜，整片要燃。

## 文件
- `引擎/`：zscript.py 镜头表（排拍）、zscenes.py 全部场景、zrender.py 渲染合成、mapx.py 西北暗金地图（换题材改 PLACES/MOUNTS/RIVERS/REGIONS 和 LON0/LAT0/K）、side.py 线描侧面/背影英雄、fig.py 小兵、kit.py/scenes.py 基础件、beats.py 测拍、extend_bgm.py 加长 BGM、zgo.sh 两进程渲染+混音。
- `BGM/`：bgm_原曲.mp3（样片原声，140BPM）、bgm_加长版_280拍.mp3（原曲 0–156 拍 + 96–156 拍 + 156 拍到结尾）。
- `参考视频/样片_戚继光.mp4`，`样片截图/`（样片抽帧、左宗棠每镜抽帧）。
- 字体用仓库根目录 `fonts/` 的 MaShanZheng-Regular.ttf（毛笔标题）、NotoSerifCJKsc-Black.otf / NotoSerifSC-Bold.otf（小字）。

## 环境
`pip install -q numpy cairocffi pillow librosa soundfile`；把仓库 fonts/ 拷进 ~/.fonts，再 `fc-cache -f`。新片先 `cp -r 引擎 /workspace/work/<题目>/war/`，旧版不覆盖。

## 节拍与剪法（学样片）
- 用户给什么视频就用它的 BGM（硬规则：必须用参考视频里的 BGM）。`python3 beats.py 视频` 量出 BP/T0 和每拍能量，不够长就用 extend_bgm.py 按 16 拍乐句接长。样片这首：BP=0.4285584，T0=0.1161619。
- 前 16 拍静奏铺垫，放倒叙钩子（如“一口棺材，跟着大军出关”），**第 16 拍闪白砸片名**。
- 一般 4 拍切一镜，镜内 2 拍换一次动作；战役高潮改成 2 拍甚至 1 拍一切（对砍→劈倒→骑兵→格挡连切）。
- 停顿拍放黑场加一句话（“可伊犁，还在俄国手里”），下一拍闪白重砸。
- 每镜都缓慢推近；每拍都有一下推镜脉冲，4 拍一重；乐句开头闪一下故障。

## 画面语言（学样片）
- **顶部居中毛笔大标题**（4–8 字）逐字落下，下面画红色下划线，下一行是白色小字说明；出处灰色小字放底部；右上角红竖线加“年份·地点”；左上角是生卒年进度条。
- 转场轮着用：墨迹炸开（ink）、光刀斜着划过全屏（streak，带横甩）、闪白重砸（drop）、红闪加震屏（kill）、故障闪（glitch）、推镜砸（slam）。
- 兵器特写：掠光扫过刀身或炮身，加刻度尺作对比。散景光斑、余烬、扬尘、速度线一直铺着。
- 大字连砸：一拍砸一个字（如“收/复/新/疆”），字后面炸开红墨，再扩一圈冲击波。
- 收尾：夕阳下的背影，左右两边竖排诗句对称，最后片名卡发光，最后一重拍火花四溅。

## 战斗（重点，每片至少 12 个打斗或攻城镜头）
`S_duel(var=…)`：
- clash 刀刀相撞：两人对冲，刀交叉的那一下火花爆散，冲击波环扩开，局部闪白。
- cut 一刀劈倒：主角冲上去，一道刀光弧，对手倒地，溅起红墨。
- parry 格挡反击：先挡住，再反手一刀。
- charge 冲阵：主角带速度线冲过去，连爆火花。
- 用 seed 控制镜像和近景（seed 是奇数就镜像，能被 3 整除就拉近景），连着几镜不重样。
- 另有 `S_cav` 骑兵剪影对冲加扬尘、`S_siege` 大炮轰城（炮弹轨迹、爆炸、碎砖）、`S_fallcity` 敌旗倒下、我方旗升起、英雄举刀。

## 英雄
- 只画侧面和背影，不画正面。冲阵对砍的主角用年轻武将（左宗棠片里是刘锦棠，当年 32 岁）；统帅（左宗棠）用背影挂帅、侧脸特写，衣冠按时代画（清代暖帽、红缨、顶珠、花翎、辫子）。
- 敌将同样用线描侧面，换头饰（turban 头巾），披风用青蓝色。
- side.py 的帽子：qing / turban / he / helm / mian / guan / bun。胡须：none / short / long / white / grey。

## 地图（战争风规则照旧）
暗金纸面、三角群山、沙漠点彩、湖泊用墨青色、河道是淡金线。行军用金线一点点画出来，进攻用红箭头，敌占区用红色光晕扩散，收复的城一圈金色光环扩开；用人物圆章代替小人，结论用红印章砸下（危 / 克 / 收复 / 收回）。

## 叙事
开头先倒叙钩子，再砸片名，然后快速讲人物前史，接着讲危局、朝廷争论、方略（大字），再进入战役连打，最后回到开头的钩子首尾呼应，交代结局，收在诗句和片名卡上。史实先按正史核过，出处写在底部小字里；有争议的写“史载不一”。结尾不固定用提问。

## 流程
1. 测拍、规划乐段，写 zscript.py：每镜一行，格式是 (起拍, 场景, 参数, 标题, 小字, 出处, 年份·地点, 特效)。
2. `python3 zrender.py sheet /tmp/s.jpg` 每镜抽一帧，用 read_file 检查：标题不压人头，人物胳膊腿完整，地图不露边。
3. `bash zgo.sh`（两个进程）→ ffprobe 确认有视频轨和音频轨 → display_file 交付。
4. 坑：渲染循环里必须先写 `sf = frame(t)`，再调 `sf.get_data()`，否则 cairo 表面被提前回收，会段错误。
