# 《吴佩孚：四年封神，一夜崩塌》音效方案（无背景音乐，只有音效）

全片不用任何配乐（不用 score*.py / synth.py），sfx.py 用 numpy 逐个合成音效，按镜头切点和画面动作（印章落下、炮火、转场）对齐，最后做软限幅 + 响度归一（峰值约 -1.5 dBFS，整体 RMS 约 -20 dBFS）。

## 音色库（全部 numpy 合成）
| 名称 | 用途 | 合成方法 |

| rain | 冯军夜行军 | 高通噪声 + 随机雨滴脉冲 |
| tele | 电报嘀嗒 | 750Hz 正弦按摩尔斯节奏开关 + 按键咔哒 |
| boom / expl | 炮声、爆炸 | 噪声爆发低通 + 45–60Hz 低频下滑 thump + 长尾隆隆 |
| mg | 机枪 | 10–12 发/秒的短噪声脉冲 |
| rifle | 步枪 | 单发短噪声 crack + 回声 |
| plane / bombfall | 飞机、炸弹 | 锯齿嗡鸣 + 螺旋桨调幅；下落哨音频率下滑 |

| steps | 行军脚步 | 多人错位的低频 thud + 沙砾噪声 |
| stamp | 盖印“咚” | 80→45Hz 正弦下滑 + 纸面拍击噪声（随 stamp() 自动对齐） |
| paper | 纸张、卷轴展开 | 带通噪声沙沙 |
| coins | 银元、支票 | 高频非谐泛音短叮当 |
| heart | 心跳 | lub-dub 低频双击，可加速 |
| gong / impact | 重锣、低频冲击 | 非谐泛音长衰减 + 30–50Hz 冲击 |

| shutter | 封面闪光灯 | 咔嚓 + 闪光“噗” |

## 混音
- 每个切点自动一记轻 whoosh（-26dB），印章自动一记 stamp。
- 底噪类（海浪/风/雨）铺满所在镜头，首尾 0.3s 淡入淡出。
- 总线：先按 0.5s 窗做轻压缩，再 tanh 软限幅，最后峰值归一到 -1.5 dBFS，避免爆音。
