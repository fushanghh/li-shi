# 史海风（学自“在唐朝嫌老婆话多”抖音样片，账号史海夜航）

参考：`/workspace/skills/shihai/参考样片_唐朝休妻.mp4`，`参考截图/style.png`（6张大图）、contact.png、motion.png、trans.png。
用户要求：学这种人物、地形、建筑、物品、表情、动作的画风。只学画风与方法，不照抄样片的具体构图、台词和道具组合；每期按本集文案重新设计场景。

## 技术底座
纯代码 Python + cairo 逐帧 + ffmpeg，1920×1080 30fps，无 AI 生图。可复用 qban / qq-lishi 的渲染管线、字幕显影、镜头工具（先 load `qban` 看环境步骤；字体 Noto Serif CJK SC，沙盒重置后从 /workspace/skills/yuxi/字体/ 拷进 ~/.fonts 再 fc-cache）。人物库要新写，不能用 Q 版大头。

## 人物（和 Q 版的最大区别）
1. 比例：写实偏瘦长，头约占身高 1/7，脖子细长，身体像一根竖条；站姿微驼、头前探，侧身 3/4 视角为主。
2. 线条：细深褐描边（#2e1b0f，约 3px@1080p），平涂填色，只加一层很淡的阴影色块，没有渐变。
3. 手臂：“橡皮管”长手臂，粗细均匀、可弯成弧线，没有肘关节转折；手是一个椭圆小拳头/手套（无手指），拿东西时椭圆贴在物件上。
4. 皮肤：暖棕黄（约 #c08a5a，暗面 #94502c），脸颊一抹淡红晕。
5. 五官：极简。常态是一条弧线的半闭眼+一根短眉+小鼻尖线+一道嘴线；震惊时一只眼变成大白圆+黑点、嘴变成小 O；生气眉压低成一字斜线；得意时眯眼咧嘴露一排白牙。男角可有一撮胡须线。
6. 发型/冠帽：女子黑色高髻，髻上横插金簪+红珠，耳旁两缕；男子黑色幞头，脑后垂两根长软脚，会随动作甩动。
7. 服饰（按朝代换）：唐女为青绿半臂（#a8b28a）+ 高腰朱红长裙（#c0392b）+ 奶白披帛，从肩上绕成两条细长环垂到膝下，走动时飘；男子奶白圆领袍（#e4d0b0）+ 褐色腰带，袍摆到小腿，裤脚灰褐。
8. 动作：鞠躬作揖、跪坐、伸臂递物、指点、双手抱胸、扭头、回头怒视、点头说话（嘴开合）、身体前倾争吵、转身离去。动作幅度靠身体整体倾斜+长手臂弧线完成，配极小的上下“呼吸”起伏。
9. 漫画符号：头顶“！”、“？”、对话气泡里“…!”“…?”逐个弹出叠满；怒气用红色弧线/旋转环；震惊时身后一圈金色圆环光晕。

## 建筑与地形
1. 室内：木构架、深棕梁柱、竖向木格窗（窗格后面是逆光的奶黄亮面，形成一条条亮栅）、屏风（米白底+青色波浪/山纹）、朱红坐垫的矮榻、木地板横纹。
2. 室外：夯土院墙+灰瓦屋檐、木门、晾衣绳挂布、远处一两层压暗的山影剪影、天空赭黄到暖褐。
3. 景深：前景人物清楚，中景家具，背景墙/窗压暗一档；画面四角大暗角。
4. 物件：油灯（细高灯台+小火苗，有光晕）、香炉与牌位（黑底金字）、纸书信（竖排大字+虚线代表小字）、毛笔会自己写字、灶膛有火、包袱、礼盒等；重要物件发金光、周围飘小金尘。

## 光与色
- 整片暖棕调：#2e1b0f / #442c19 / #593c23 / #715d40 / #927955 / #cdbb8b，点缀朱红 #8d442d–#c0392b 和青绿。
- 窗户或门洞打进一道柔和体积光（半透明奶黄梯形），亮处有轻微 bloom；冲突偏红、正面偏金、悲伤偏灰褐。
- 空中漂浮少量亮尘粒。

## 画面信息设计
1. 画中画回忆/想象：画面一侧开一个带细金边的矩形框，框内降饱和、偏褐，演过去或设想的事，右下角小字标签。
2. 图标格卷轴：一长卷分成几格，每格上方汉字编号、下方一个简笔图标；讲到哪格高亮（红框），否定就画大红叉；反复出现做记忆锚。
3. 字幕：左上角两行大号粗宋体，奶白字带深色阴影；关键词换金黄或朱红并加同色下划线，逐词模糊淡入。左上角极小字“人物和场面都是示意”。

## 镜头与节奏
- 约每 2.1 秒一个镜头，切点卡在配乐小节线上（样片 112BPM，一小节 2.14s）。
- 镜头内必有一个动作：缓推近、轻横移、或人物做一个动作。
- 转场：带运动模糊的快速横摇（2–4 帧），或一道金色竖光线擦过；同场景内硬切换景别（全景→中景→近景）。

## 交付前检查
出抽帧表：人物比例是否保持瘦长、披帛和幞头软脚有没有摆动、字幕不压人脸、暗角下人物不过暗。
