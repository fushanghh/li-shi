# 白起风（baiqi）

样片：《白起的一生》（116 秒、33 镜，BGM 为用户提供的 hypnotic funk 140BPM，原曲 88 秒按拍加长）。
画面底子 = 玉玺黑影风（先 load `yuxi`、`heiying` 看总规则），本技能只写“卡点燃剪”这层的不同之处。

## 包内结构
- `引擎/beats.py`：抽 BGM + 测 BPM + 拍网格(T0, BP) + 每拍能量表（找副歌、停顿拍）。
- `引擎/extend_bgm.py`：BGM 太短时按 16 拍乐句复制拼接（交叉淡化 12ms，节拍网格连续）。
- `引擎/script.py`：镜头表 `(起拍, 场景key, 年份·地点, 出处, 计数, 字幕, 特效)`，特效 = drop / slam / glitch / kill / bury(停顿拍静默后爆发) / quiet / end。
- `引擎/render.py`：按拍定时的渲染器（节拍推镜、震屏、闪白、红闪、故障闪、28字/秒打字机字幕+重点字弹跳、左下计数器）。
- `引擎/scenes.py`：白起 33 个镜头函数 + 通用件 `baiqi()`(红披风主角, 剑发光) `army()` `spear_row()` `arrows()` `embers()` `smoke()` `speedlines()` `wall_city()` `map_bg()`（俯视战术图）。
- `引擎/kit.py`：yuxi 剪影工具库（sil/horse/palace/mountains/flame…）。
- `引擎/go.sh`：`N=2 bash go.sh` 并行渲染 → 拼接 → 混 BGM（`bgm_ext.wav`）出成片。
- `参考视频/样片_白起_卡点10秒.mp4`（含 drop 和标题砸字）、`样片截图/全片抽帧.jpg`、`字体/`。
- 用户的 BGM 原文件不入库（版权），每次从用户给的视频里重新提取。

## 流程
1. 环境：`pip install -q numpy cairocffi pillow librosa soundfile`；字体（仓库根目录 `fonts/` 的 Noto Serif SC）拷到 `~/.fonts` 后 `fc-cache -f`。复制 `引擎/` 到 `/workspace/work/<题目>/film/`。
2. `python3 beats.py 用户视频.mp4`：记下 BP/T0；看能量表划乐段——前奏(安静)→drop→副歌→间奏(安静)→副歌→停顿拍→尾声。
3. 时长不够：`extend_bgm.py` 复制一段副歌（跳接点在 16 拍乐句头）。
4. 写稿排拍（核心）：
   - 一句一镜，默认 8 拍一镜（140BPM≈3.4 秒），字幕≤2 行、每行≤16 字；乐段尾可 6 或 12 拍。
   - 前奏安静段放钩子（2 句：结局反差）；**drop 第一拍砸片名**（大字从 1.8 倍缩回 + 闪白 + 故障）。
   - 间奏安静段放蓄力镜头（筑坝、对峙、谋划）；副歌放战役与杀伐。
   - **音乐停顿的几拍 = 全片最狠的一刻**：黑场 + 一句小字（“那一夜”），停顿结束的重拍红闪+震屏+计数器暴涨。
   - 结局放尾声段，最后一镜问句互动（“战神，还是杀神？”），音乐结束后留 2 秒淡出。
5. 视觉：每镜按字幕内容专门画场景（黑影风规则）；主角唯一颜色=红披风，唯一发光体=剑；俯视战术图用于讲计谋（佯攻/切断）；大字道具一律放 y≥420，避开左上字幕区。
6. `python3 render.py sheet` 每镜抽一帧拼图，read_file 检查重叠和过暗 → `N=2 bash go.sh` 后台渲染（2 核约 2 分钟/分钟片长）。
7. 交付：display_file 成片 mp4。

## 和 yuxi 默认规则的区别
- **有背景音乐**（用户提供的 BGM），这是白起风的定义；不配旁白，不另加音效。
- 字幕 28 字/秒（yuxi 15），重点字【红】〖金〗出现时 1.5 倍弹跳回落。
- 计数器只记史书明载的数字（如“史书记载·白起斩首 24→27→42→47→92 万”），“数十万”这类不入计数，写在字幕里。
- 史实先核查（史记·白起王翦列传、战国策、资治通鉴、维基百科），右上标出处。
