# 白起风（baiqi）· 2026-10-31 战争风版

样片：《白起的一生·战争风》（116 秒、33 镜，BGM 为用户给的 hypnotic funk 143.55BPM，原曲按拍加长）。
2026-10-31 用户否掉旧的玉玺黑影版：**主角不用黑影**，要线条画出威武、酷炫、热血的武将；玉玺风不合适，改**战争风**（先 load `zhanzheng` 看地图/场景/印章总规则）；主角**只用侧面和背影，不要正面**，突出英雄形象；白起要**年轻帅气**（无浓须，束发长尾随风）。本技能写的是“战争风 + 卡点燃剪 + 线描英雄”这层。

## 包内结构（引擎/）
- `beats.py`：抽 BGM + 测 BPM + 拍网格(T0, BP) + 每拍能量表（找副歌、停顿拍）。
- `extend_bgm.py`：BGM 太短时按 16 拍乐句复制拼接（交叉淡化 12ms，网格连续）。
- `script.py`：镜头表 `(起拍, 场景key, 年份·地点, 出处, 计数, 字幕, 特效)`，特效 = drop / slam / glitch / kill / bury / quiet / end。
- `render.py`：按拍渲染器（节拍推镜、震屏、闪白、红闪、故障闪）；战争风 UI：底部居中宋体字幕 28字/秒+重点字弹跳、字幕下一行灰字出处、右上红竖线+“年份·地点”、左上时间进度条（前294——前257）+“史书记载·白起斩首 N 万”计数器；`MAPNUM` 里的地图镜头左上自带大数字，计数器让位。
- `side.py`：**线描英雄**。`side(c,x,y,s,t,hat,beard,cape_col,armor,arms,face,stride,kneel,...)` 侧面（face=-1 朝左），`back(c,x,y,s,t,arms='sword'|'raise'|'none')` 背影，`head_side()` 侧脸（可放大做特写/圆章）。
  - hat：he 鹖冠（秦将）/ helm 兜鍪+红缨 / mian 冕旒 / guan 文官冠 / bun 布衣发髻；beard：none / short / long / white。
  - arms：rest 按剑 / fwd 剑指前方 / raise 举剑 / slash 劈斩（p 0→1）/ point 指令 / down 垂剑 / offer 托盘 / bow 拱手 / hang 垂手。
- `fig.py`：线描底层件（shape/line/tube/hatch 排线阴影/lamellar 甲片/sword 发光剑/soldier 秦赵小兵）。
- `mapw.py`：战争风暗金地图（经纬度投影、纸纹、金河、三角群山、淡金国名），`set_cam(lon,lat,zoom)`（zoom≥0.8 免露边）、`city()` 金/红城点+光环、`march()` 金线行军、`arrow()` 红箭头、`flagpin()` 方旗、`jag()` 冲突锯齿线、`army_block()` 方阵块。
- `scenes.py`：33 个镜头函数 + 通用件 `sky mts ground wall palace throne troops flag arrows embers smoke speedlines stamp(红印章落下震) badge(人物圆章) scroll_sword`。
- `kit.py`：字体、text、glow、vgrad、flame、moon 等基础件。`hero.py`：早期正面人物稿（已弃用，只留参考）。
- `go.sh`：`N=2 bash go.sh` 并行渲染 → 拼接 → 混 BGM（`bgm_ext.wav`），成片先写 /tmp 再拷回。
- `参考视频/样片_白起_卡点10秒.mp4`、`样片截图/全片抽帧.jpg`、`字体/`。用户给的 BGM 已入库：`BGM/bgm_原曲.mp3`、`BGM/bgm_加长版_116秒.mp3`（143.55BPM，按拍加长，go.sh 用前转成 bgm_ext.wav）；用户给新视频时仍重新提取。

## 流程
1. 环境：`pip install -q numpy cairocffi pillow librosa soundfile`；字体拷到 `~/.fonts` 后 `fc-cache -f`。复制 `引擎/` 到 `/workspace/work/<题目>/war/`。
2. `python3 beats.py 用户视频.mp4` 记 BP/T0，看能量表划乐段；不够长就 `extend_bgm.py`。
3. 写稿排拍：一句一镜，默认 8 拍一镜，字幕一行为主；前奏放钩子（结局反差），**drop 第一拍砸片名**；间奏放蓄力（筑坝、对峙、谋划），副歌放战役；**停顿拍=最狠一刻**（黑场+“那一夜”，重拍红闪+震屏+计数暴涨）；最后一镜问句互动。
4. 镜头分配：约一半地图镜（讲行军、计谋、包围、战果，地图内持续画线/亮点/跳数字），一半战场镜（城墙、宫殿、火海、洪水、方阵、箭雨）；地图镜用人物圆章代替小人。
5. 英雄镜头：大场面用**背影**（红披风迎风、高举/垂握发光剑，面对千军/火海/坑边），动作戏用**侧面**（劈斩、剑指、冲锋），情绪戏用**侧脸大特写**；配速度线、余烬、逆光光晕。敌将同样线描侧面，换兜鍪和青蓝披风。
6. 战果一律用红印章砸屏（“斩首二十四万”“坑杀”“赐死”），印章不挡主角脸。
7. `python3 render.py sheet` 每镜抽一帧拼图，read_file 检查（字幕不压出处、背影头部不压标题、地图不露边、人物在暗底看得清）→ `N=2 bash go.sh` 后台渲染（2 核约 15 分钟/2 分钟片）。
8. 交付：display_file 成片 mp4，不覆盖旧版。

## 燃点规则（2026-10-31 用户加）
- 每镜都要有酷炫特效：刀光拖影、剑气弧、冲击波环、火星爆散、尘土炸开、速度线、闪白、红闪、震屏、慢动作后猛加速、定格。
- 多放打斗场面：侧面劈斩对砍、冲锋撞阵、骑兵对冲、一剑破阵；多放战争场面：千军方阵、旗海、箭雨遮天、攻城云梯、火海、洪水灌城。
- 字幕用简短语句（一句 4–10 字为主，像口号），关键词做成大字砸屏。
- 大字和动画都卡 BGM：重拍落大字/印章/刀光，每拍推镜或闪，乐句头故障闪，副歌密集连砸，停顿拍黑场后重拍爆发。

## 规则
- **有背景音乐**（用户给的 BGM）是白起风的定义；不配旁白，不另加音效。
- 计数器只记史书明载数字（24→27→42→47→92 万），“数十万”写字幕不入计数。
- 史实先核查（《史记·白起王翦列传》《战国策》《资治通鉴》），出处写在字幕下灰字。
- 主角永远不画正面。
