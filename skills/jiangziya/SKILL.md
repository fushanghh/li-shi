# 姜子牙风（原Vibe神话风；学自《Vibe神话系列·姜子牙》样片，另学《中国神话·第3集 杨戬》）

参考：`参考样片_姜子牙.mp4`（本目录）（112.8s，576x1024 竖屏，30fps），截图 `参考截图/`。杨戬样片在 `/workspace/work/ref7/v.mp4`。
学：画风、打击感、剧情设计、特效、音乐与动画卡点。铁律：只学方法，不照抄造型、构图、台词，每期按文案重新设计。可和 `zhidiao` 纸雕山河混用。

## 版式（竖屏 9:16；水浒系列改为 3:4 竖屏 1080×1440）
- 三段式：上方细花边条（回纹）→ 中间约 4:3 主舞台 → 回纹分隔线 → 黑底字幕区 → 最下一大条陶器纹装饰（同心圆+波浪线+三角，橙底黑纹）。像一只彩陶罐上的连环画。
- 右上角小账号水印。

## 画风
- 主舞台底色陶土橙（#b8602a–#d27a3a），纸纹颗粒和中心微亮；关键段换调：婚礼大红、夜/封神深蓝黑星空、火光金黄。
- 前景地形纯黑剪影（礁石、山崖、树、芦苇、屋顶、台阶），远景压暗一档的橙褐山/房，两层。水面墨绿带白色漩涡纹。
- 人物：小而细长的黑袍剪影，只有脸/胡子/须发是白色；配角用墨绿、暗红衣色区分阵营；纸偶式关节摆动。
- 天空符号：黑色太阳带锯齿光芒、白色如意卷云小图标、神仙在金色光环里坐云。
- 道具很小很符号化：招牌、扁担、算命幡、四不像、打神鞭、封神榜卷轴。

## 字幕
底部黑区两行居中，衬线粗体米白字，关键词橙色。押韵短句、快板感，一句 ≤8 字两行，一句一镜。

## 打击感（核心）
1. 计数器：右上角大号金字“赔×1→×2→×3”“学道4年→28年”，每次跳变放大到约 1.3 倍再弹回、金色描边和小阴影，上方一行小字标签。重复型剧情全靠它抖包袱。
2. 拟声字：“咚！”“呼——！”“哼！”“唰——”手写粗字在动作同一拍弹出，配风线、烟团。
3. 大标题印字：“囍”“不干！”“伐纣！”“封神！”金色粗字厚描边压在画面上方，砸下时整屏轻震。
4. 动作到位帧停 2–3 帧再走，像皮影敲板。
5. 特效：白色烟团爆开、风线、金色放射光和光环、整团金焰、火光照亮人群、星点闪烁、旋转法宝光圈。

## 音乐与卡点
- 配乐 95.7 BPM（一拍 0.627 秒），国风电子节拍，几乎每拍都有强起音，响度平稳不留白。
- 切镜卡在小节上：多数镜头 2 拍或 4 拍；重复段每 2 拍一切，越到高潮越密。
- 计数器跳变、拟声字、大标题砸下都落在正拍；动作起势在前半拍，到位在正拍。
- 段落转换换调+换场，落在乐句第一拍。

## 音乐主导（附加规则，用户林冲片反馈）
- 音乐掌控全剧：先定音乐段落结构（慢起→铺垫→提速→高潮→余韵），再按音乐排镜头和动作。
- 必须有一段“音乐变快、打架也变快”的激情段：BPM 提升或双倍速律动（16分踩镲、贝斯16分、鼓加花），出招间隔从1拍缩到半拍/四分之一拍，剪辑和计数器跳得更密。
- 每个打击点对齐重拍，铜管/太鼓/金属声与画面冲击帧同一帧；提速前短暂抽空+上升音效蓄力，再砸下。
- 音色随剧情换：笛子主题、二胡悲段、琵琶轮指打斗、铜管合唱高潮。不能只有鼓。

## 剧情设计
- 一生压缩成约 110 秒，三幕：失败 → 等待 → 逆袭 → 反转收尾，回到开头画面首尾呼应。
- 手法：重复三次+计数器；每段一句押韵快板；反差梗；结尾回到开头画面。
- 开头直接用主角最出名的画面做钩子+系列片名。

## 出场方式（学自杨戬片，同为 95.7BPM）
1. 主角立在巨大圆盘（落日/月）前，同心光环，标志物在旁；名号大字砸下。
2. 下一拍切脸部大特写，“人设标语”砸下，一句话讲清他最大的矛盾。
3. 代表冲突的道具飞来，主角用招牌能力当场处理，火星炸开——3秒内亮出性格。
4. 紧接 4–6 个武术亮相姿势，每拍一个，金色粒子风暴环绕。
5. 片尾回到同一画面，标语后补一句回答，首尾呼应。

## 杨戬片拆解
- 造型：全身纯黑剪影 + 细橙色刻线勾甲片（方肩甲横纹、身甲竖片、V形护胸、圆扣）；短方手臂配米白圆拳；宽马步、厚靴；黑披风动作时甩出；脸米白长椭圆尖下巴，黑杏仁锐眼、粗眉上挑，额头标志符号；长黑发垂肩；高冠黑底橙线；兵器刃部米白；随身一只标志伙伴。新角色出场挂小名签（上行拼音小字，下行中文名号）。
- 场景：陶土橙底+纸纹；远山深一档橙；黑云带橙卷纹；黑树配粉花；地面黑带+橙色回纹；上下回纹边，底部彩陶纹大条。
- 切镜：开场每 1–2 拍一切；叙事段约 2 拍一切；对打段几乎每拍一切，每切换一个姿势+计数器跳一次；尾声回到 2 拍一切。
- 声音：响度平稳，最强起音都落在拍点；对打段连续每拍一个重击。
- 转场：几乎全是正拍硬切；大段落之间同场景换调；“法天象地”用比例突变；变身段每拍一个“A变X / B变Y”标签；片尾回到开场画面+标语，黑场。
- 打击：撞击点金色放射圆+火星；计数器小框在右上，数字越跳越大（×2→×4→…→×300）。

## 杨戬片叙事要点
①标语是个悖论（“听调不听宣”），全片用剧情把两半各演一次，结尾一句话解开；②字幕每句两行，第一行事件、第二行转折/结果，关键词橙；③高潮后用一个小动作（拱手拒赏）定性格；④配角首次出场一律挂名签；⑤重复段全靠计数器，数字越往后越夸张。

## 编剧模板
钩子（名号+标语）→ 身世苦难 → 学艺（大字计数“一年→二十年”，师父试招）→ 绝技习成（大字招名）→ 获神兵、立目标 → 小战（计数器）→ 必杀成名（大字）→ 名声（立庙、兄弟来投）→ 再遇强敌（回合计数，大字绝招）→ 斗智 → 收束（拒封赏）→ 回到开场标语。

## 落地到代码
cairo 管线：竖屏；先定 BPM（建议 96），按拍生成镜头时间表；`punch(t_hit)` 缓动（0→1.3→1.0，0.18 秒）给计数器/标题/拟声字，`shake(t_hit)` 给标题砸下；音效短鼓、木鱼、锣在同一拍叠加。交付前出抽帧表检查字幕区、计数器不压人物。
