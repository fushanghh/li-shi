# 参考片拆解：《假如你只住世界第一大城》（抖音 iwanau，149 秒，2026-10-31 拆）

> 只学方法，不抄构图、台词和美术。截图总表见同目录 `截图总表_1~4.jpg`。

## 1. 一句话概括
同一个“你”（黑剪影 + **红腰带**）按时间顺序搬进 17 座“当时世界第一大城”，左下计数器从 4 万涨到 4200 万；结尾揭晓：路上走着的人全都系着红腰带——“像你一样，从别处搬来的人”。

## 2. 结构（149 秒，约 32 镜，平均 4.5 秒一镜）
| 段落 | 时长 | 做法 |
|---|---|---|
| 钩子 | 0–10s | 三句三镜：起点（第一站只有 4 万人）→ 终点（最后一站 4200 万，大数字在城市灯海上滚动）→ 地球仪上画出迁徙红线（“中间这五千年”） |
| 反常识 | 10–15s | 今天的第一名，“不是东京”——先立一个大家以为的答案再推翻 |
| 片名 | 15–18s | 片名大字直接压在第一站画面上，随即淡出进入正文，不单独做黑底标题卡 |
| 正文 | 18–125s | 一站一镜（偶尔两镜）：年份 → 城市 → 一个“你在这里做的具体小事” |
| 互动点 | 约 85s | 公元 1000 年“三份史料、三个答案”：三联竖屏分屏（开封/巴格达/科尔多瓦，各标出处和数字），抛问“你，选哪个？” |
| 回收 | 125–135s | 地球仪：16 条红线连起所有站——“五千年，你搬了 16 次家” |
| 反转 | 135–143s | 地平线上一排人走过，每个人都系红腰带：主角原来是所有人 |
| 收尾 | 143–149s | 向观众提问（“你是从哪里，搬到现在这座城的？”）+ 片名 + 出品署名，最后是平台引导页 |

## 3. 画面
- **不再全片压暗**：每站按真实时代和地方配色——两河黄昏金、尼罗河青绿、巴比伦宝蓝夜、罗马白红斗兽场、长安暖黄、杭州水墨灰、伦敦煤烟褐、东京电车亮绿、雅加达紫红夜。暗色电影感只用于钩子、地球仪和结尾。
- **扁平矢量场景，有地标**：伊什塔尔门、金字塔、斗兽场、圣索菲亚、朱雀大街、清明上河图虹桥、紫禁城红墙、自由女神……一看就知道在哪。
- **贯穿主角**：纯黑剪影 + 一条红腰带（唯一贯穿全片的颜色记号），体量小（约画面高 1/4），常站在画面中下方或从侧面走进画面；配角是更灰、更淡的剪影。
- **“你”在做事**：记账（特写手握芦苇笔刻泥板）、撑船、在斗兽场跟着欢呼、在智慧宫抄书、站红墙下、被推进电车……每站一个动作，让人代入。
- **同构图对比**：同一镜里换状态讲时间——罗马“人群站着→全体举手欢呼”；斗兽场“百万人→只剩三万人、广场放牛”；紫禁城红墙前树从绿变黄变绿（“一住三百年，换了十几个皇帝”）。
- **一个发光/高亮物**仍在：“1”字金色数字立在城市剪影上当“第一名”标记，还在后面跟着移到新城市。
- 镜头：缓慢推拉 + 场景之间柔和叠化/淡入，没有硬切（ffmpeg 场景检测 0.3 阈值下零硬切）。

## 4. 文字与 UI（以 1080p 计）
- **字幕**：左上，粗衬线白字约 54px（比现在的 60–96 小），两行。**第一行先出，停一拍，同一镜里再出第二行**——第一行交代事实，第二行给细节或反转。关键词标橙红（数字、城名、反常识点），少量金色。
- **右上标签**：红短线 + 年份（约 40px 粗）；第二行 地点 · 今属国家；第三行小灰字 = 人口数字 + 学术出处（Modelski 2003、Chandler 1987、Morris 等）。
- **左下计数器**：小地球仪（上面画到当前站的红线）+ “第 N 站 · 城名” + “约 XX 万人”大数字。站数与人口双计数。
- 片尾署名一行：“XX 出品 · 把故事一帧一帧画给你看”。

## 5. 声音
- 无旁白，纯字幕；配了一条轻音乐（拨弦类）。按用户默认，我们的黑影风仍**不配背景音乐**，除非用户点名要。

## 6. 文案方法
- 全片一个主题词（“第一大城”）+ 一个人称（“你”）+ 一个递增数字（人口）。
- 每站句式：“你搬到X——”+ 一个让人记住的具体细节（“金字塔已经五百多岁了”“广场上放起了牛”“早高峰有人专门把你推进车厢”）。
- 中段设一个“没有标准答案”的史料分歧，让观众在评论区选。
- 结尾把“你”从一个人变成所有人，再把问题抛回观众自己的生活。

## 7. 可直接用到黑影风的新招
1. 贯穿主角记号（红腰带/红围巾）+ 结尾“人人都有这个记号”的反转。
2. 第一行先出、第二行后出的两拍字幕。
3. 双计数器（第 N 站 + 数值）和带路线的小地球仪。
4. 同构图换状态讲时间流逝（人群动作、废墟化、树变色）。
5. 三联分屏“史料打架”互动镜。
6. 片名压在第一镜上，不做独立标题卡。
7. 每段按时代地域换主色，暗色只留给钩子与结尾。
