# 黑影风历史短视频

就是“玉溪画风”那套黑剪影电影感做法。技术细节、模板、kit.py 函数全部按 `yuxi` 技能执行：开工先 load `yuxi`。素材在 `/workspace/skills/yuxi/`，参考工程 `/workspace/work/sz2/`（《第一个站出来的人》）。

## 风格要点
- 暗色电影感背景 + 纯黑剪影人物（靠帽冠区分身份）+ 全片只有一个发光主体。
- 纯字幕，无配音、无音效、无音轨；左上粗衬线白字逐字显影，【红】死亡/惩罚，〖金〗重点。
- 右上“年份 · 地点”+出处小字；左下贯穿全片的计数器（画在推镜之外）。
- 每镜慢推，死亡瞬间红闪。

## 用户已定的偏好（覆盖 yuxi 旧规则）
1. 所有画面元素按本集文案专门画：每个镜头的背景、建筑、道具、人物动作都表现那句字幕的内容，不准各集共用同一套背景。不需要省 token。
2. 一屏一意，一个核心观点（可用心理学/博弈论/社会学概念当名号）贯穿全片；全白话，古文极少且紧跟白话。
3. 开头不固定用“假如你是X”，也不必每次“片名最后点亮”；开头先概括全片讲什么、点出关键人物和结果，概念只用一句解释。
4. 参考片只学方法，不模仿构图、台词、视觉结构。
5. 史实先核查并标出处；交付前每镜抽帧检查。
