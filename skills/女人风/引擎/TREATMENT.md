# 随份子从哪儿来 —— 制作说明
- 画风：慕夏新艺术（粗外轮廓细内线、暖色平涂、马赛克色带外框）× 神话风关节木偶（侧面律、8 头身、肩肘髋膝头关节）。场景全部为真实历史现场：周代丧家庭院、秦末沛县吕公宅、莫高窟、五代敦煌民居院落与社邑宴席、明代厅堂、贾府荣庆堂、民国婚礼堂屋、现代婚宴礼金台。
- 规格：4:3 1440×1080，24fps，约 154 秒，27 镜头；结尾回到开场构图，可循环。
- 结构：钩子（第三场婚礼随八百）→ 标题 → 先秦赙赠 → 刘邦贺钱万 → 敦煌女人社（社条、人各出油面粟、席上喧拳罚一筵）→ 明清凑份子 → 红楼梦攒金庆寿 → 民国礼账 → 今天红包扫码与人情负担 → 回到本意 → 结尾。
- 配乐：自写，D 宫五声调式，112 BPM；笛子主旋律、古筝分解和弦、梆子/堂鼓/镲/锣；各段换律动（周：半拍慢鼓；汉：梆子俏皮；敦煌：手鼓+十六分古筝；宴席：密鼓轮指；民国：唢呐；结尾：独奏笛→全编制收锣）。切镜、出字、动作都卡在拍点上。
- 音效：人声嘈杂、脚步、红包窸窣、落箱、铜钱、毛笔、竹简、风、驼铃、倒油、碗翻酒洒、银锭、鞭炮、算盘、扫码“叮”、心跳。无旁白、无人声台词。
